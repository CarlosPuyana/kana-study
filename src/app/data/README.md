# Kana data

Current dataset counts:
- Hiragana: 105 standard entries.
- Katakana: 105 standard entries.

The set contains modern base kana, dakuten, handakuten, `vu`, and standard yōon combinations. Extended katakana used mainly for foreign-word transcription (for example ファ/ティ/チェ) is intentionally not mixed into the first learning set yet; it can be added as a dedicated variant when that study mode is defined.
