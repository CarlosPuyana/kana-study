# Notas propuestas — Beta Manga × Mazos local en Invitado

BORRADOR: no publicado ni autorizado para publicar.

Manga permite añadir palabras revisadas manualmente a mazos locales desde el diccionario.
Puedes estudiar con Otra vez/Bien, deshacer un repaso antes de cerrar la sesión diaria,
consultar vocabulario confirmado y buscar apariciones textuales en OCR. El diccionario
sigue mostrando lectura, significados, contexto y referencias de Gramática antes de crear tarjetas.

## Dónde se guardan tus tarjetas

Las tarjetas y su progreso están solo en este navegador y perfil, dentro del espacio Invitado.
**No se sincronizan con tu cuenta.** Antes de borrar datos del sitio, cambiar de navegador
o dispositivo, exporta una copia desde Mazos → Datos y progreso y guárdala fuera del navegador.

La copia local compatible conserva contenido, identidades e historial de estudio y se restaura
únicamente en un Invitado vacío. No incluye archivos Manga, imágenes, OCR completo ni diccionario.
El JSON puede contener texto privado y no está cifrado. Una descarga no es sincronización continua.
No uses modo privado como archivo permanente: el navegador puede eliminar datos o aplicar cuotas.

## Qué ocurre al iniciar sesión

La primera versión pública de Manga × Mazos está limitada a Invitado. Tus funciones habituales
de cuenta, incluido Japanese 1500, siguen disponibles. Los mazos personalizados previos de una
cuenta se conservan, pero no se exponen para crear/modificar progreso en esta versión porque
aún no cuentan con backup portable. Cerrar sesión permite volver al Invitado original.
No se copian mazos entre Invitado y cuentas automáticamente.

## Límites de esta publicación

El propietario comunicó siete comprobaciones funcionales superadas en Chrome de escritorio
el 26/10/2026. No se dispone de versión exacta ni de evidencias adicionales. La automatización
complementa esa aceptación con Chromium. Safari y móviles Android/iOS físicos siguen pendientes:
no anunciar compatibilidad validada en esas plataformas antes de completar la checklist.
Se necesita conexión para la carga inicial y los assets; no se certifica arranque frío offline.
Las glosas del diccionario distribuido son españolas, aunque la interfaz admita ES/EN/CA.
No se anuncia custom cloud, traducción persistente de ejemplos ni generación lingüística automática.
